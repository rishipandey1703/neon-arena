# ⚡ NEON ARENA

### Multiplayer Mind Battle

NEON ARENA is a real-time multiplayer game for **2–8 players** where players compete across five fast-paced mental and reaction-based challenges.

Players can create or join a room using a short room code, play together in real time, earn points across multiple rounds, and compete for the highest final score.

## 🎮 Play Online

**Live Game:**  
https://neon-arena-cjip.onrender.com

No account or installation is required.

Open the game on two or more devices, create a room, share the room code, and start playing.

---

## 🧠 Game Modes

NEON ARENA contains five rounds:

### 1. ⚡ Flash
React as quickly as possible when the signal appears.

Faster players receive higher scores.

### 2. 🧩 Memory Grid
Watch the displayed tile sequence and reproduce it correctly.

Each correct tile contributes to the player's score.

### 3. 🎯 Decoy
Identify the symbol that differs from the others.

Correct answers earn points.

### 4. 🎲 Risk
Choose between a safer reward and a higher-risk reward.

- Safe: **+40**
- Risky: **+100 if successful**
- Risky failure: **−30**

### 5. 💥 Chaos Finale
A fast-paced final challenge where players tap targets to maximize their score.

The finale uses a **×2 scoring multiplier**.
